# Language audit — 2026-10-03

Audited English, Korean, Chinese, French, German, and Spanish. Chinese presentation uses Traditional Chinese consistently.

## Changes

- Load UI messages and all four localized datasets as one bundle. Commit a language only after the complete bundle is available; the latest selection wins overlapping requests.
- Translate page copy, navigation, filters, options, accessibility labels, tooltips, polls, generated rating evidence, wizard instructions, simulator labels, and the 404 page. Update document titles and the HTML language with the selected locale.
- Synchronize localized cars, features, models, and settings with the current English structure: 50 vehicle records, 28 features, 130 models, and 130 settings. Keep model/vehicle identities, numerical values, configuration keys, defaults, URLs, and serialized control enums canonical.
- Refresh open detail dialogs when language changes. Refresh imperative simulator status/label text immediately, including while simulators are off screen and their animation is inactive.
- Replace the English-only embedded statistics dashboard with native localized charts/tables using the same public aggregate data. Retain the original dashboard link and a localized snapshot fallback.
- Correct automotive terminology and mistranslations, including parked device state, software forks, lane tracking, factory control, torque adjustment, reinforcement learning, and fleet terminology. Preserve negation in safety guidance and translate complete sentences instead of fragments.

## Translation and content boundaries

Translation verification combined drafts from public display text with 201 manually reviewed source overrides, automotive terminology corrections, structural checks, and rendered browser checks. This is not independent native-speaker certification of every sentence.

Official model names, vehicle names, authors, branch names, units, filenames, and code/configuration identifiers remain unchanged. Descriptive vehicle variants are localized for display while lookup/export identities remain canonical.

Curated forum highlights/reviews are translated. Uncurated external forum replies without a verified translation show a localized link instead of leaking an English excerpt into a non-English page. Linked external websites retain their own language behavior.

Changes are local and have not been deployed. Existing unrelated workspace changes were preserved.
